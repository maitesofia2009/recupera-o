# Guia de Recuperação - React

Projeto que desenvolvi para a atividade de Programação de Aplicativos. É um guia de estudos interativo com os principais conceitos de Git, Node.js, React e desenvolvimento web que vimos em aula.

## O que o projeto faz

- Mostra 8 cards com resumo, exemplo prático e erros comuns de cada tema.
- Tem um botão em cada card para marcar o conteúdo como revisado, atualizando o contador lá em cima (de 0/8 até 8/8).
- Tem uma área de "Minhas dúvidas" onde dá para escrever e adicionar perguntas na lista (sem deixar cadastrar campo vazio).

## Tecnologias que usei

- React
- Vite
- JavaScript
- CSS (Grid e responsivo para celular)

## Como rodar o projeto no PC

1. Baixe o repositório:
   `git clone https://github.com/SEU-USUARIO/react-guia-recuperacao.git`
2. Entre na pasta:
   `cd react-guia-recuperacao`
3. Instale as dependências:
   `npm install`
4. Rode o projeto:
   `npm run dev`
